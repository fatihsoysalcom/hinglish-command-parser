# Hinglish Command Parser

This example demonstrates a simple, rule-based approach to understanding Hinglish (Hindi and English mixed) commands without relying on large language models (LLMs). It parses predefined keywords to identify actions, directions, and objects, simulating the core logic for a low-cost robotic arm control system on platforms like Raspberry Pi.

## Language

`python`

## How to Run

Save the code as `main.py` and run it from your terminal using `python main.py`.
